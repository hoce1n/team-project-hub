# Support

Thanks for using Team Project Hub. This page points you to the right place for
help.

## Documentation

- The [README](README.md) covers setup, the tech stack, and the Docker Compose
  workflows.
- [CONTRIBUTING.md](CONTRIBUTING.md) describes the development environment and
  how to submit changes.
- [CHANGELOG.md](CHANGELOG.md) lists notable changes per version.

## Getting help

- For general questions, open a GitHub Discussion if Discussions are enabled on
  this repository.
- For bug reports, open an issue with the bug report template.
- For feature requests, open an issue with the feature request template.

## Security issues

Do not open a public issue for security problems. See
[SECURITY.md](SECURITY.md) for the private reporting process.

## Community

Be respectful and follow the [Code of Conduct](CODE_OF_CONDUCT.md) in all
interactions.
